# 🚀 Ejercicios Prácticos de C# - De Cero a POO

El objetivo de este repositorio es documentar mi aprendizaje y servir como guía práctica para cualquiera que esté dando sus primeros pasos con **C#**.

---

## 🛠️ Tecnologías y Herramientas

* **Lenguaje:** C# (.NET 8.0+)
* **Entorno:** Aplicaciones de Consola
* **IDE Recomendado:** Visual Studio / Visual Studio Code / JetBrains Rider

---

## 🎯 Conceptos Practicados

A lo largo de los ejercicios se abordan los siguientes temas clave:

* **Sintaxis Básica y Variables:** Tipos de datos, conversión de tipos (`Convert`, `TryParse`).
* **Estructuras de Control:** Condicionales (`if`, `switch`) y bucles (`while`, `for`, `foreach`).
* **Manejo de Métodos y Control de Flujo:** Uso de `break`, `continue` y modularización del código.
* **Manejo de Excepciones:** Control de errores comunes (como `DivideByZeroException` o entradas no válidas) con bloques `try-catch`.
* **Programación Orientada a Objetos (POO):** Creación de clases, propiedades, métodos y encapsulamiento.
